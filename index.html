04 / Evidence

Acceptance is behavior, not a green checkbox.

Passed gates

  • Foundation: shell, route, navigation, and pane accepted.
  • Read models: four sanitized operational summaries accepted.
  • Rollback: known-good live artifact preserved.
  • Public safety: secrets, private paths, ports, logs, and runtime state excluded.

Open gate

  • AX/CUA: native WindowServer bounds exist, but no usable AXWindow or renderer subtree is exposed.
  • Promotion: Task 3.1 is not live and the plugin is not promoted.
  • Next boundary: resolve the Electron/macOS runtime issue with an isolated, supported diagnosis.
05 / Operating lessons

What the build proved.

The point of the public endpoint is not to show motion. It is to preserve decisions and make the next action obvious.

Small surfaces compound.

A route, pane, and read model can be accepted independently before the runtime surface is ready.

Rollback is part of delivery.

The known-good artifact stays protected while a new runtime path is investigated.

Healthy backend ≠ usable Desktop.

Backend readiness and WindowServer presence do not prove AX/CUA or renderer acceptance.

Public documentation needs a threat model.

Evidence can be useful without publishing secrets, private endpoints, machine metadata, or internal routing.

Current endpoint

The public build is live. The private promotion gate is honest.
