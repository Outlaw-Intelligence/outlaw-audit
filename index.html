The authority model

Three avatars. No blurred permissions.

Each avatar has a distinct identity, voice reference, Hermes profile reference, and allowlisted capability set. AIRI never becomes the tool authority.

Decision lane

Zeus

Commander and primary operator. Conversation, planning, and sanitized status reads. Dylan remains the final human authority.

Counsel lane

Odin

Build lane

Thor

The system boundary

Voice is a pipeline, not a permission slip.

MIC / TEXT → local ASR adapter ↓ OLYMPUS ADAPTER → allowlisted avatar ID ↓ HERMES PROFILE → bounded authority lane ↓ LOCAL TTS → validated audio ↓ AIRI RENDERER → state + lip-sync Loopback-only. No direct shell. No private prompt export. No cloud fallback.
Hard boundary

What the avatar cannot do

Olympus rejects arbitrary shell, filesystem, browser, computer-use, hardware, subprocess, credential, and unbounded tool requests. Handoffs are structured, explicit, and human-approval gated.

The public manifests contain environment references—not secrets, local paths, ports, prompts, or machine state.
Apple Silicon implementation

Build it in layers.

Do not start by wiring a voice button to a giant agent. Prove each layer on an arm64 Mac, then connect it to the next.

1
Verify native toolingConfirm arm64 Node, pnpm, Xcode command-line tools, and a Metal-capable local runtime.
2
Run AIRI aloneClone the upstream AIRI workspace, install with its declared pnpm version, build, and prove the renderer before Hermes.
3
Separate the Hermes lanesCreate isolated Zeus, Odin, and Thor profiles without cloning private credentials, channels, memory, or browser state.
4
Install the adapter boundaryAllow only health, chat, avatar-state, handoff, and status-read. Bind locally. Enforce body, timeout, origin, and output limits.
5
Add voice one leg at a timeProve ASR, conversation, TTS, playback, visible state transitions, and finally microphone-to-lip-sync.
6
Run acceptance and publish only sanitized artifactsManifest validation, security scan, runtime evidence, and public documentation all pass before calling a lane live.
