[Outlaw Audit](#outlaw-audit) is a portfolio case study for an AI-assisted website auditing concept that turns website observations into structured improvement opportunities.

## Local preview

No build system is required. Serve the static site with any local HTTP server:

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>.
